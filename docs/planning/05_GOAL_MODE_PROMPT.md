## 三、项目背景

项目是 RoboMaster 2027 微型自主无人机预研。用户明确底层保留 PX4，允许由工程论证决定上位机接口。当前主接口选择三轴速度与偏航角速度；位置可作为定位有效后的辅助技能。首版不直接控制电机或替代 PX4 姿态内环。

最新需求：飞机从中场机库附近起飞，前往敌方底线附近约15×15cm的目标识别模块，完成接近、识别、对准和后续规定任务。模块类别尚待确认，不能默认它是普通机器人小装甲、基地周围装甲或顶部飞镖检测模块中的任一种；不默认允许在敌方目标加视觉标记。

2026官方历史规则参考场地28×15m，中线到端线纵向约14m；这不是2027精确场地坐标。场地存在高地、公路、隧道、基地结构、地面高度/纹理变化和动态机器人，不是空旷平面。2027前瞻包含中场机库、制高点等变化，以实际取得的对应赛季资料为准。

项目规则快照为2026-09-09发布的2027前瞻及继承记录，包含质量/外廓关系、全包围桨保、至少10s悬停及继承的单次飞行至多30s等。其适用方式、计时、容差和后续更新必须核查，不能把旧赛季内容不加区分地套用。不要把10s悬停自动解释成每次出击必须占用10s，先核对其属于制作验收还是运行要求。

已知硬件背景：四旋翼；4×T-MOTOR1103 8000KV＋Gemfan2216S-3；MicoAir743v2-AIO-45A/PX4，实板revision与固件待确认；MTF-02P光流/测距；Pi5 Ubuntu24.04 ARM64算法验证平台；USB双目2560×960 MJPEG，每目1280×960，60FPS为请求值；约67.6718mm双目基线为候选标定；下视IMX219为实验相机。开发电池3S300mAh；最终能源方案未确定。

设计外廓118–120mm，参考质量160g不是整机实测。质量、重心、惯量、推力曲线、整机供电、Pi内存/功耗/散热、最终机载平台和部署状态均存在缺口。

本机历史检查：Windows11、RTX5080 16GB、约32GB内存；E:\isaac\IsaacLab 与 E:\isaac\env_isaaclab 已有IsaacSim5.1/Lab环境，基础官方四旋翼步进通过，有依赖冲突；未证明项目训练/视觉任务通过。2026-10-09只读WSL检查未发现已安装发行版，PX4 SITL NOT RUN。这些是历史检查记录，涉及当前行动时需低成本复核。

当前路线：PX4基础闭环＋传统感知/几何定位＋有界传统控制优先；根据已确认的能力缺口引入监督学习；PPO、VIO、完整SLAM、Pegasus和Isaac↔PX4运行时桥接按需要后置。可以重新论证暂定选择，但不能违反用户保留PX4的约束。
