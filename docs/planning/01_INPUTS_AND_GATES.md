## 3. 任务和导航工作表

首个研究演示暂定为固定目标相对接近与保持，不含接触任务。必须区分：

- 地面允许的标记作为研发定位工具，和赛事目标允许的感知方案。
- 目标可见时的视觉伺服，和目标丢失/返库途中需要的导航。
- PX4 有效局部速度，和足以返库的局部位置/航向精度。

填写目标尺寸、距离、视场后计算像素占据；填写路线、最长失去参照的时间和库位捕获范围后建立漂移容限。缺失这些输入时不选择最终网络和 VIO。

## 4. 决策门

| 门 | 放行条件 | 未通过时做什么 |
| --- | --- | --- |
| G0 接口验收 | W01合同＋W02锁定工具链、真实PX4理想定位正常/故障矩阵与日志/退出通过；开始条件与必测范围见首阶段 | 修合同/环境/网关，不增加感知/RL依赖 |
| G1 视觉基线 | 目标定义与像素预算成立，标定可复核，传统定位有误差报告 | 改采集/目标条件或定位方法 |
| G2 学习感知 | 已记录传统失败样本，数据划分有效，全链算力有余量 | 补数据或继续传统方案 |
| G3 实机任务 | 精确固件、质量/推力/供电和无GPS估计均有证据 | 回到硬件/定位，不用SITL代替实物 |
| G4 学习决策 | 同观测下传统控制/规划有明确不足且不是感知错误 | 保留基线，不启动PPO |

阶段门只限制依赖它的工作；不同证据组可以独立推进，不要求所有未知都回答后才允许做第一项软件实验。
