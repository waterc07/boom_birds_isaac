## 2. baseline bearing 的解释修订

- baseline 只有 bbox，**没有物理 anchor**；旧报告把 bbox 中心 bearing 与标签绿灯参考点直接比较，得到约 9.1–11.5° 误差，localization TP=0。
- 本包拆分后：
  - 标签 bbox 中心与绿灯参考点本身已有约 0.28–5.06° 差；
  - baseline 预测 bbox 中心与标签 bbox 中心仍有约 5.65–11.74° 差；
  - baseline 预测 bbox 中心与绿灯参考点约 9.1–11.5°。
- 结论修订：旧 baseline 的“绿灯方位误差”**不是同一评价对象**，应标为“不直接可比”；但预测框相对标签框中心的偏移也真实存在，不能把全部失败归因于定义差异。旧 localization TP=0 保留，但不能作为物理 anchor 精度结论。

## 3. improved 退化原因修订

- 旧报告把 improved 零召回部分归因于阈值/开发视角。本包证据细化：
  - improved 测试正例中 18 帧只有 presence 标签、无 bbox，不能做目标重叠判定；
  - 9 个 bbox 可评估正例中，4 个存在 target-overlap 候选但低于 0.65（约 0.528–0.592），5 个 target-overlap 候选非常低（约 0.34–0.50）；
  - 全局最高分候选常落在非目标区域（IoU 0–0.2，score≈0.55–0.61）；
  - 阈值扫描 .55→.65 无良好工作点（.55 TP15/FP22，.60 TP4/FP20，.65 TP0/FP2）；
  - 多视角模板中 center 主导 43/49，left 0/49，route near 6/49；单模板单独运行也没有稳定收益。
- 因此“零召回”的主因是**模板/候选覆盖与分数不可分**，阈值是次要门；不是实现路径中的 gate/generation 抑制，也不是单一坐标变换 bug。
- 旧正式结果不重算；本包只追加解释。
