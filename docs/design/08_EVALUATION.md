# v1.2 实验设计与验收

所有数值为PROPOSED的初始研究门限，用户接受架构不等于接受这些数值。P0/P1运行后冻结使用域与门限，再做正式比较；若调整门限要换评估版本并保留旧结果。

## 证据层级

S：仿真；R：真实日志重放；H：机载/硬件在环；F：真实飞行。每个结果注明证据层级。P2理想深度/真值观测标记ORACLE，不能记为DEPLOYABLE。训练的teacher/critic特权观测与导出actor做字段级隔离检查。

## 数据与统计协议

调试smoke用10固定seed；正式每个候选至少3个训练seed，每个checkpoint评估相同的100个冻结episode（总计300个策略-episode结果）。同时报告每个模型和汇总结果，不能将共享场景/模型的300结果当成完全独立样本而夸大统计置信。

训练、调参验证、最终保留测试用独立场景/seed；同一录制序列不能拆帧分到不同集合。最终集只在选定候选后使用。配置、代码、模型、资产、预处理hash一致才可直接对比。训练预算按环境步数和墙钟时间都记录。

成功、碰撞、超时、估计失效中止分别计数；分母包含全部启动的有效测试episode。重试单列，不能删除失败；基础设施崩溃记录为invalid并说明，不偷偷算成功。成功要求到达且停止；碰撞优先判失败，不能碰到目标后用到点奖励掩盖。

## 各门初值

| 门 | 使用域与指标 | 初始判据/未定项 |
| --- | --- | --- |
| G0 | 环境/上游/合同 | 指定解释器官方例运行；合同测试PASS；上游SHA/许可/差异可追踪 |
| G1 | 空场到点/停止 | 成功率≥95%，碰撞0；0.3m范围、速度≤0.2m/s连续0.5s；20s超时 |
| G2 | 简单静态障碍 | 成功率≥95%，碰撞率≤1%，报告最小净空/耗时；这是研究晋升门，不是实飞安全承诺 |
| G3 | 可部署观测与算力 | 相同G2场景；噪声/延迟/丢帧另列；较ORACLE成功率下降≤5个百分点作为筛选，且必须满足绝对G2门 |
| G4a | 返程重捕获 | 初值成功率≥95%；最大漂移须小于实测捕获域减余量，数值等机库几何后固定 |
| G4b | 机库末段 | 落点/朝向误差来自落点有效区、机体外廓与容差；几何未知不编造厘米数；下降/误落统计 |
| G5a | 机载重放与部署 | 推理P95≤20ms、全链P95≤100ms初值；P99/截止违约/峰值内存/热/功耗同时报告 |
| G5b | PX4与受控飞行 | 控制响应、状态有效域、失联、接管及各模式实测；无统一虚构成功架次，按场地与风险冻结协议 |
| G6 | 基地/装甲/阵营 | 检出、身份、父子关联、相对误差分开；冻结负样本集误授权任务动作=0，报告样本数；执行判定依官方规则 |
| G7 | 完整任务 | 成功率、任务时间、能量/余量、返库率与故障恢复；正式目标待赛季规则和机体参数冻结 |

## 必做对照

- P1比例制导 vs PPO，同动作/同运动模型；不要求PPO在空场必胜。
- P2简单几何避障对照 vs NavRL方法参考PPO；记录同观测与同速度限值。
- P3 ORACLE距离/深度 vs RGB+状态 vs RGB+状态+有限前向距离；后者要声明设备/视场/量程假设。
- 视觉单帧 vs 帧堆叠或GRU；只在提高效果或鲁棒性时保留额外记忆。
- 融合状态 vs 加原始光流/IMU：如无明确收益不增加输入。
- actor原生 vs 导出 vs 量化：数值和闭环指标均比较，模型大小不是唯一指标。

## 故障与泛化

P1：reset残留、动作NaN、过期、边界出生、timeout。P2：窄通道、终点不可达、贴墙、停住刷奖励。P3：不同纹理/亮度、模糊、延迟突发、掉帧、传感无效。P4：机库遮挡、地面台阶、误匹配、航向漂移。P5：时钟回跳/重置、通信丢失、估计origin变化、CPU拥堵。P6：红蓝互换、中立/未知颜色、基地正确但小装甲错误。

每组扰动先限定范围，再独立留出超范围测试。失败时应拒绝动作或进入已验证的降级流程；不能让策略猜测的数值伪装成有效传感。

## 交付产物

每次正式实验产生run manifest、resolved config、逐episode CSV/JSON、汇总、失败片段和结论。晋升报告列出有效使用域、已知失败和回滚模型；三类结论：可晋升、需修改、当前条件不可行。文档链接与算术核查仅证明资料完整性。
