# v1.2 首阶段：P0/P1工程与基础运动

2026-10-11。启动依据为用户确定的开源复用方案；当前任务交付规划。具体执行清单见[实施计划](../superpowers/plans/2026-10-11-p0-p1-foundation.md)。

## 首轮目标

在已有Isaac Lab环境中建立可独立运行、可重放、可度量的无障碍到点与停止任务。动作采用速度＋偏航率，真实PX4不是训练时依赖。基线包含简单比例制导对照和成熟PPO，不自行实现PPO。

## 输入和环境

主工作区E:\isaac\proj_boom_birds。现有Isaac环境路径/版本从本机重新只读检查并登记；历史有官方四旋翼步进记录，不等于新任务通过。NavRL和DiffPhysDrone只读固定版本、阅读依赖/许可/模型/训练代码，不先完整安装。上游许可不明的代码先仅做行为和论文参考，复制前确认适用许可与来源。

## 首轮配置（PROPOSED，仿真实验而非实机约束）

场景10×6×3m，空场；仿真碰撞包络半径0.12m仅作初值，机体资产实际几何与接触检测另登记。水平限速1m/s，垂直0.5m/s，偏航率0.5rad/s；策略20Hz、episode 20s；到点半径0.3m且速度模长≤0.2m/s连续0.5s。起点/终点分布保留≥1m间距和地面/边界净空。无障碍阶段不渲染相机以降低资源成本。

首版按1环境验证，再扩8/32/64测资源，依据显存/内存锁定并行数，不直接上千环境。动力响应参数是ASSUMED且显式配置；P5以PX4响应更新并回归，不能称为已经辨识。

## 首轮产物

- env/manifests下可复现的环境与上游版本记录。
- contracts与动作缩放、frame、时效、epoch测试。
- Isaac Lab velocity executor，使用现有适用控制器或清晰受限的速度跟踪控制；不直接把速度当推力。
- 无障碍到点环境、简单制导对照、PPO连接、同评估集报告。
- checkpoint/配置/种子/日志manifest与可重放入口。

## 首轮通过条件

合同测试通过；采样动作和实际速度响应能逐条解释；episode的terminated/truncated正确；相同checkpoint与冻结seed可重放；训练集与验证集不混用。正式统计门限见[验收](08_EVALUATION.md)。

失败排查顺序：单位/动作符号→时间步与控制响应→reset/episode→奖励与终止→训练超参数。先不要用增加网络、换仿真器或引入真实视觉掩盖基础问题。

首轮无需真实装甲图像、机库标记、全场定位、WSL/PX4构建或现有实机日志。迁移阶段保留对这些必要条件的验证责任。
