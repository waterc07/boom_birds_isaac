# ADR-001：PX4速度与偏航率接口

2026-10-11，v1.2。保留原接口原则；首个研究基线采用速度＋偏航率，实际迁移P5验证。用户已确认PX4 1.17定高与通信，不扩展为速度闭环已验。

策略归一化动作在水平机体FLU框架解码，转换本地ENU三轴速度及逆时针偏航率；网关再转NED=[vy,vx,-vz]和偏航率负号。MAVLink frame=1、mask=1479；具体类型见[架构](../design/02_ARCHITECTURE.md)。

选择速度接口是为了复用PX4内环、适配局部视觉任务；代价是需要有效速度估计。姿态/角速度/电机接口不是仅改输出维度就可替换，须重新验证动力学和控制责任。[PX4 1.17 Offboard](https://docs.px4.io/v1.17/en/flight_modes/offboard)

建议20Hz策略、50Hz发送、150ms TTL，均PROPOSED。重发不续期；模式ACK不等于模式生效；无效估计下零速度不保证悬停。学习策略无模式、解锁、参数权限。只有实际速度接口能力不足的证据才重新评估下层接口。
