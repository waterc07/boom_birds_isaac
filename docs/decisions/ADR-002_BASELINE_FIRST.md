# ADR-002：开源基线与渐进研究

2026-10-11，v1.2。状态：用户已确定架构方向。本记录替代2026-10-09“传统闭环先行、学习仅按缺口引入”的研究启动顺序，原文已归档。

采用Isaac Lab主工程、NavRL首个导航/PPO参考、DiffPhysDrone轻量视觉/可微训练对照；复用成熟PPO实现。先建立基础运动与简单避障仿真，不等待旧项目或PX4联仿。保留简单传统控制对照以发现奖励和接口问题，不将其建设成另一套完整导航栈。

P1/P2可用标明的理想观测；P3必须比较真实可得观测。持续稠密双目深度非默认，单目充分性同样未证明。传感器和网络通过任务覆盖、成本与消融决定。

详细边界见[开源基线](../design/09_OPEN_SOURCE_BASELINE.md)，验收见[实验协议](../design/08_EVALUATION.md)。最终模型与训练方法未冻结，改变主工程/接口需新的差异和证据。
