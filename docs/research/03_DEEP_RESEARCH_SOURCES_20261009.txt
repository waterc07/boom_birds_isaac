New server-focused SPEC CPU 2026 benchmarking suite has results for a Raspberry Pi 5 - updated tools feature more tests and can run a wide range of systems


The Standard Performance Evaluation Corporation (SPEC) has launched SPEC CPU 2026, a major upgrade to its CPU benchmarking suite, replacing SPEC CPU 2017. Designed primarily for server performance evaluation, it now includes 52 benchmarks — nine more than its predecessor — and more than double the codebase. Emphasizing portability, it supports diverse systems, from Raspberry Pi 5s to multi-CPU server setups. The benchmarks measure integer and floating-point performance across speed and throughput metrics, yielding SPECspeed and SPECrate scores. To ensure consistency, the benchmarks rely on deterministic behavior and extensive code modification, excluding system-level variability and non-portable code paths. Applications like llama.cpp and whisper.cpp were excluded due to behavior divergence when stripped to portable code. Initial results highlight a range of system performances, from Raspberry Pi 5 (3.72 base) to high-end servers like Dell’s PowerEdge M7725 (1,270 base for integer throughput). Intel Xeon and AMD EPYC dominate the server benchmarks, while some consumer systems like MacBook Pro (M5 Pro) and Minisforum PCs also appear. SPEC CPU 2026 is available at tiered pricing, replacing SPEC CPU 2017 on November 3, 2026. Existing 2017 users can upgrade at a discount, with free or discounted options for academia and nonprofits.
