# 后续任务验收与门限冻结方法

2026-10-09。此协议补齐S1–S5的判断条件，所有实验NOT RUN，初值PROPOSED。真实任务/几何/实测决定最终门限，不能看到保留测试结果后放宽门限。缺少必填数据则相应任务未放行，不阻塞独立软件S0。

## 共同验收卡

负责人在后续实施时创建版本化task_card（拟建，非现成程序），包含任务类型/真实或研发、目标几何/行为、路线与参照、传感器/标定/固件、观测许可、启动条件、完成事件、误差/速度/帧龄/净空/时间/能源门限、场景矩阵、失败条件、重复数/真值来源、退出/清理。

先用开发样本确定观测误差/资源上界→按几何/任务分配允许误差→证明预算有正余量→冻结卡/测试数据/哈希→运行保留测试。负责人提出数值PROPOSED；用户/队伍明确接受后记ACCEPTED，当前交付不自动升级建议。赛季硬约束不能放宽。

测量、估计、控制、安装误差分列，初版以保守界相加，不默认独立高斯。P95不是绝对安全界。错误目标动作、过期运动指令、模式未确认或硬边界越界记录FAIL；任务失败但安全收尾另记恢复结果。

## 误差、时延、时间如何变成门限

视觉条件矩阵还须覆盖真实曝光下的移动/转动拖影、MJPEG质量/码率、左右同步及明暗变化；采集方法见预算报告。静态目标照片集不能独立放行运动中的身份或位姿。

通道沿路线最小障碍距离c，机体包络半径r，定位界e_n、控制界e_c及其他余量m，要求`c−r−e_n−e_c−m > d_motion`，其中`d_motion=v*tau+v²/(2a)`只含延迟/制动，不再次加入包络/误差。高度与上方盲区若无法观测、图纸也不能保证净空则路线不放行。漂移试验覆盖真实最长无参照时间，局部1m结果不能证明14m导航。

末段分别分配横向/高度/距离/角度容差给几何、控制、帧龄位移。用预算报告制动式解出允许总延迟/速度；余量为负就降速/增距离/改观测。接触另按接触约束，不要求整个无人机装进15cm装甲平面。

时间各段取实测上界：起飞、远段、捕获、任务、返库或落场、降落及储备；时间不足中止任务。能量用负载积分/截止与可用储备，定期判断可否完成回收路径，不等百分比突然触底。

## 样本与放行层级

S0重复数见首阶段。后续每条件至少3次先定位问题，不能用于成功率承诺；正式样本数按冻结的可接受失败率/置信要求制定。n次独立同分布零失败时，一侧95%失败率上界`1−0.05^(1/n)`仅在假设满足时适用。条件/分母/置信区间公开，代表性不足只覆盖已测域。

G1只放行目标感知，G3只放行有证据的局部实物阶段；W05–W08任务卡各自放行，不自动跨场/接触/返库。当前S0–S5均NOT RUN。规划完成、制作合规和自主任务通过是不同结论。
