## 模型假设隔离

已完成定高/通信为USER_PROVIDED历史实物结果，未审阅原日志时不冒充本轮MEASURED。准确固件只确认1.17，补丁/build待登记；不重复要求证明能定高，不自动放行速度Offboard或无磁力计跨场导航。

S0默认SIH机体只证明接口，不填未知真实惯量/推力为理想值。后续微型模型登记质量/完整外廓、旋翼轴/方向、惯量正定/三角关系、推力/反扭矩/电机滞后与饱和；拟合模型绑定保留测试，不能直接标独立实测。几何、物理和PX4分配描述同一机体。

## 失败情景和反方审查入口

远距像素不足/错模块→G1阻止末段；光流退化/航向漂移/重置→G3阻止跨场；过期命令续发/模式拒绝→G0阻止网关晋升；质量供电/热超限→G3阻止实机；默认GPS/标记/真值泄漏→相应试验作废；任务预算不闭合→W08阻止完整任务。具体反方审查与修订证据在[规划验收](../reports/PLANNING_ACCEPTANCE.md)；已完成规划层审查，本轮不执行新增实物动作；已有定高/通信按用户证据复用。
