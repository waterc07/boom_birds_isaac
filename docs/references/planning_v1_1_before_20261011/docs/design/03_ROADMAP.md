## 阶段依赖与可并行部分

用户已完成PX41.17无GPS光流定高与MAVLink通信；W04先复用并记录该基线，只补水平速度/航向/漂移与未覆盖制作/动力证据。W09为独立功能分支，I0资料/观测可与攻击视觉并行，I2运动能力依赖W04；不强迫先完成完整攻防才能验证攻击闭环。

S0=W01+W02；S1=W03；S2=W04；S3=W05；S4=W06/W07按任务分别放行；S5=W08。W03录制、W04BOM可以在W02准备时独立开展；实机任何运动仍需G3和后续授权。W06不是返库侦察的必需依赖，W07不是攻击落场任务的必需依赖；总体范围两者均保留。

第一阶段不要求微型模型全部实测，默认SIH动力只证明接口。后续锁微型SIH参数必须推力/质量/惯量来源一致；需要真实视觉仿真时才评估Gazebo/Isaac。升级工具的代价、触发和回退记录在ADR。

## 验收数值与统计制度

后续任务的具体验收卡、观测/真值、门限制定和失败条件见[任务验收协议](../planning/08_TASK_ACCEPTANCE_PROTOCOL.md)。它补齐此表的执行方法，不把后续未知门限变成当前已通过。

S0采用首阶段候选门限和故障矩阵。S1以后不预先承诺统一95%成功率/200回合；由任务风险和误差/净空预算定义可接受门限，再冻结场景矩阵及样本数。必须公布成功分母、每场景、置信区间、P95/极值、未完成和基础设施失败。测试不能仅换随机种子；真实数据按会话/场景/目标实例隔离。

指标分为任务完成、碰撞/越界、正确终止、恢复成功、资源与时间能源；任务失败但安全落地不算任务成功。接触是目标事件时与意外碰撞分开统计。人工接管/外部定位/研发标记均显式标记，不算纯自主赛事结果。

30s采用继承限制，工程试验暂以起飞状态到确认接地计时，官方起止待确认。10s制作悬停独立验证；需要侦察驻留的任务再分配驻留预算。库内充电/卸载计入循环时长，不消除飞行超时。
