# 项目设计与需求追踪

v1.1，2026-10-10；规划验收完成，实现NOT RUN。[总纲](../../PROJECT_PLAN.md)为统一入口。旧设计已归档于references/design_before_v1_20261009/design，不作为当前指令。

## 需求边界

RoboMaster2027微型无人机：保留PX4，机载自主感知和任务，中场出发至敌方底线附近模块；目标已确认敌方基地小装甲，准确安装几何、正式判定与精确地图仍待核查。非接触对准是先行研究闭环，最终接触、侦察返库卸载及能源循环仍在总体范围。拦截敌方飞镖/大弹丸是明确W09功能分支，按I0–I3验证，不要求攻击首闭环同时完成。无新增敌方视觉标记是默认研究约束；库位标记只有规则允许时部署。

主路线采用传统基线优先；监督学习解决明确感知缺口，策略学习解决同观测控制缺口。当前没有训练任务默认观测维数、网络或奖励。位置、姿态、电机接口不与速度接口混发。学习器没有解锁/切模式/改飞控参数权限。

## 证据层级与运行类型

软件合同、理想定位SITL、真实视觉离线、无GPS估计、机载全链、台架与实飞分别报告。SITL默认GPS/磁力计用于接口，不能称为无GPS性能；仿真真值只用于明确接口对照和评价，不混入部署观测。研发标记或外部定位同理。

每次试验绑定代码/固件提交、参数/标定/数据哈希、工具锁、种子与观测来源。数据采集会话/目标实例/场景分割而非相邻帧随机分割；失败、超时与崩溃均保留分母。零碰撞样例数必须公布，不能推断真实碰撞率为零。

## 架构稳定与变更

稳定接口是观测、带期限运动命令、状态有效性和任务事件。传统或学习实现替换不得改变坐标/时间合同。传感器或固件升级只重验影响的合同与阶段；观测schema/标定/坐标原点变更则使相关模型和运行记录失效。
