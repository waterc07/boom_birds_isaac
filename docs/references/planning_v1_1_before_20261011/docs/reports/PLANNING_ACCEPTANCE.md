## 官方资料核查及预算

已读取本地官方2026 V1.3规则p24/67和制作p44/46/47，渲染查看弹丸与飞镖表格。42mm球当版直径42.5±0.5mm、质量44.5±0.5g，速度上限12/特定模式16.5m/s；飞镖可主动控制方向，25m/s是检测注意值而非最高速度。颜色特征不能普遍等同敌我：飞镖有阵营LED，球不是红蓝身份目标。当前数据只用于历史场景/敏感性，不冒充2027最终参数。

官方目录列出2026规则V2.2.0，尝试的镜像规则返回404、制作规范超时；取得2027官方分享页题名为青工会PPT，并非已核实9月前瞻原手册。没有据未取得的正文推断新版值。来源/链接/页码在[专项](../planning/09_TARGET_TEAM_AND_INTERCEPTION.md)。

[拦截预算JSON](../planning/interception_budget.json)记录假设与9个速度/距离组合：5m球约7.77px，16.5m/s剩余约303ms；横移0.5m在假设2m/s²从静止下至少约707ms，未计时延/限速。结论是先核可达域/预布位，不能由已完成定高推断动态拦截成立。

## 反方检查与修订

- 实飞已完成却重复要求“证明能飞”：改为先登记/复用，补验速度、质量/时钟/故障和漂移；SITL不是既有定高前置。
- 固件1.17误当精确v1.17.0提交：SITL候选与实板完整build分别锁，未授权刷写。
- 基地识别好就盲撞装甲：基地/装甲/位姿/父子关联分别验收，失去小装甲不得继续末段。
- 红蓝切换翻转飞控坐标或攻击己方：固定ENU/NED、own/opponent在任务层派生；红蓝对称与未知/中立回归；切换使旧命令失效。
- 所有物体用红蓝色判敌我：颜色只作线索，球需来源/轨迹关系，未知归属不盲拦。
- 定高稳定即可拦截快球/主动飞镖：增加I0–I3、水平响应/全链年龄/预测不确定度和使用域；攻击与防守互斥仲裁。
