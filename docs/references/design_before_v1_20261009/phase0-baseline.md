# 阶段零：需求闭合与 PX4 最小基线计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立足以决定首个真实任务和工具链的证据，并交付可复现的 PX4 速度接口基线，减少后续硬件、感知和算法返工。

**Architecture:** PX4 负责估计与速度以下控制，上位机负责相对定位、传统制导和指令监督。先用隔离的 SITL 验证接口与模式；视觉、微型机模型、学习任务按证据逐步加入。

**Tech Stack:** Windows 资料/已有 Isaac 环境；拟用 WSL2 Ubuntu 24.04 运行 PX4 SITL；MAVLink。具体协议库及固定依赖在接口实验前登记，不继承 Isaac Python 环境。

**Spec:** [ADR-002](../../decisions/ADR-002_BASELINE_FIRST.md)、[研究审查](../../research/04_REPORT_REVIEW_20261009.md)、[输入与决策表](../../planning/01_INPUTS_AND_GATES.md)。

## Review Focus

1. 模型/发送端停更但旧命令继续重发：测试有效期不能由重发更新。
2. ENU/NED、偏航角/偏航率混淆：验证每轴方向、符号和单位。

5. 未知目标/质量被假设掩盖：决策表记录未知项和条件场景，不作实机验收结论。
