# 首个学习任务：相对目标到达与保持

版本0.2；状态：PROPOSED、NOT RUN。按用户保留PX4的要求，本任务学习制导策略，输出速度与偏航率。基础悬停和速度跟踪由PX4完成，并先作为M1基线验证。

## 1. 任务与后端

- `BoomBirds-GoalReach-Oracle-v0`：真值诊断。
- `BoomBirds-GoalReach-Proxy-v0`：M2研究任务，E0相对估计代理。
- `BoomBirds-GoalReach-Sensor-v0`：M3采用实际传感器处理与估计代码。

这些ID尚未注册。控制后端单列为F0受限飞控代理或F1真实PX4 SITL，不与观测档位混淆。当前任务替代旧VelocityHold学习任务；观测／动作schema使用v1，禁止加载旧姿态／推力动作模型。

初始场景为平坦地面、无障碍和空中稳定初态。PROPOSED初始高度0.8m，目标在水平0.3～1.0m范围，高度目标在0.6～1.0m范围，episode上限20s。目标固定在同一本地坐标系，允许在10s内到达，再连续保持10s。起飞和着陆属于M4。

## 2. 目标与状态来源

目标相对向量必须可由部署传感器获得：例如已校准标记提供的相对位姿，或在有效局部里程计中表达的目标。E0允许明确假设的误差代理；E1必须实际经过图像／标记或局部估计器。仅有光流和测距不能证明长期可靠的目标位置或返库位置。

F1中速度和姿态控制使用PX4估计状态，上位机消费PX4遥测与自己的目标估计。坐标对齐、估计器重置、时间戳和置信度均是接口的一部分。暂时没有目标观测来源时，E1任务保持BLOCKED；不能把目标真值作为部署观测补入。

## 3. actor观测schema v1

建议27维；与旧版虽然维度相同，字段语义已改变，必须按schema版本检查。

| 索引 | 维度 | 字段 |
| --- | --- | --- |
| 0–2 | 3 | 本地ENU目标相对位置估计 |
| 3–5 | 3 | 本地ENU速度估计 |
| 6–8 | 3 | 机体系估计重力单位方向 |
| 9–11 | 3 | 机体系估计角速度 |
| 12–15 | 4 | 上次仲裁后的速度／偏航率动作 |
| 16 | 1 | 估计离地高度 |
| 17–18 | 2 | 目标航向误差的sin和cos |
| 19–22 | 4 | 速度、姿态、高度、目标估计的数据年龄 |
| 23–26 | 4 | 上述四组估计的有效标记 |

目标航向来自任务配置，误差使用估计航向计算。世界真值只进入奖励、评估、Oracle或可选critic；不向actor传递真值误差、真实扰动或未测实际质量。关键不确定度由监督器检查，后续若给actor增加协方差或历史窗口，需再次升级schema。

归一化只在训练数据上拟合，评估冻结。有效标记不做连续变量归一化。无效值用有限填充值和有效标记表示，不能将0解释为有效测量。目标失锁和坐标重置触发受控处理；不默默换成真值。

## 4. 四维速度动作

网络输出`a∈[-1,1]^4`，映射到本地ENU三轴速度与偏航角速度。PROPOSED初始每轴水平速度限值0.5m/s、垂直速度限值0.3m/s、偏航率限值45度/s；水平合速度另限制为0.5m/s。加速度、变化率和高度边界由网关配置限制，数值在M1响应测试后冻结。

策略20Hz，网关50Hz；重复发送不会更新原命令的有效截止时间。PX4完成速度、姿态、角速度控制和电机分配。F0代理必须有有限响应、限幅和动力学，不允许直接设置机器人速度。

记录actor原始动作、网关仲裁后动作、PX4接收状态、实际速度和可用的饱和指标。没有遥测到的内部饱和状态不得伪造为实板已观测量。

## 5. 奖励与终止

奖励围绕目标进度、到达后的保持、航向误差、速度平滑和耗时：

`r = w_progress*(distance_prev-distance_now) + dt*(w_hold*inside_goal - w_yaw*yaw_error_squared - w_speed*near_goal_speed_squared - w_delta*action_change_squared - w_time)`

碰撞、越界和任务失败有独立惩罚；完整成功只由连续保持条件判定。奖励权重和距离尺度在首次长训练前配置并冻结，逐项记录贡献。功率模型未验证时不把速度平方或动作平方当成真实能耗。

终止：完整外廓碰撞、越界、失控、数值异常或关键状态持续失效；达到时间上限为truncated。PX4模式丢失属于失败或明确记录的安全收尾，不允许继续把策略输出当作已执行。SITL时钟／桥异常单列基础设施失败，仍计入尝试统计。

到达后保持10s，过程中离开容差区域则保持计时重新开始，episode总计时不重置。学习目标为到达与保持，不通过无限等待降低碰撞率。

## 6. 基线与训练

B0为传统相对位置比例制导＋速度限幅，输出与actor相同的速度接口；两者使用相同PX4或F0后端及相同估计观测。B1为PPO、建议两层64单元MLP。复杂障碍和视觉网络不加入首轮。

训练种子11、23、47；先固定动力、小范围目标，再加入可信范围的目标估计误差、速度响应变化、时延和丢帧。每次随机化必须说明依据。初始64环境，资源测量后再扩到256；F1先从单机开始，不假定可同规模并行。

部署策略选择只使用验证集。最终固定测试集每个训练种子至少200回合，传统基线用相同场景集合。训练／评估分割覆盖初态、目标、扰动和估计误差，不能只换种子。

## 7. PROPOSED验收

- 20s内完成目标到达及连续10s保持，整个保持窗口水平目标误差<=0.15m、高度目标误差<=0.08m，全程无碰撞；成功率>=95%。
- 报告到达时间、完整保持时长、最大／P95目标误差、速度、饱和、命令年龄、模式变化和失败分布。
- F0／E0与F1／E1分别报告；后者尚未跑通时，结果不能称为PX4闭环或可部署验证。
- 对比传统制导的成功率和到达时间；只有证据表明有改善，才声称学习有收益。未改善时优先保留传统制导，不为了使用RL而替换成熟控制。
- 若目标观测丢失，分别记录任务失败与安全收尾，不能把安全降落计为目标任务成功。
