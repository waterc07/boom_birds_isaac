# 参数缺口、模型假设与风险登记

版本0.2，研究参数PROPOSED，PX4保留为确定架构约束。这里的未测项是需要关闭的研究条件，不是允许实现时随意补值的空白。

## 1. 参数来源制度

每个参数记录value、unit、status、source、measured_at、uncertainty／可信范围、applicable_configuration和替换位置。来源状态：MEASURED（有测量证据）、VENDOR（厂商资料条件下）、ASSUMED（研究假设）。完全未知的值不填写伪精度；由最小模型初始化方案明确给值后才能启动仿真。

用于研究的ASSUMED模型有自己的版本，不覆盖真实配置。参数更新触发相关动力／控制／感知回归。学习到的系统辨识参数单独记录拟合数据与保留测试误差，不能直接标为独立实测。

质量0.160kg和包络0.120m只说明该组假设满足快照质量公式上限0.1755kg，不证明真实整机达到该质量／尺寸。参考推重比目标>=2.5并非已有能力；不能默认训练模型已经满足目标。

## 3. 关键风险与验证优先级

| 风险 | 后果 | 优先验证 | 何时阻止继续 |
| --- | --- | --- | --- |
| Pi＋飞控＋传感器＋保护结构质量／功耗超预算 | 最终平台不可落地 | BOM质量／功率累计，硬件布局核对 | 阻止真实整机结论，不阻止显式假设模型研究 |
| 悬停依赖不可得位置或无漂移速度 | 仿真成绩无法迁移 | Oracle／E0／E1差异，真值隔离测试 | 阻止部署候选晋升 |
| 动力控制模型过于理想 | 策略利用不存在的力矩／推力 | 逐电机分配、饱和、时延和辨识 | 阻止真实控制能力结论 |
| 30s任务预算不足 | 完整任务不能完成 | 路径、起降和10s悬停时间预算 | 阻止规则模式成功判定 |
| 低纹理／反光／遮挡使感知失效 | 定位丢失、碰撞或无法降落 | 场景外分布和故障注入 | 未验证回退的场景不得进入候选使用域 |
| Windows Insider与依赖漂移 | 实验启动或退出不稳定 | M0固定环境和多次启动退出测试 | 阻止长训练基线验收 |
| 16GB显存／32GB RAM不足 | OOM、掉速、批量实验中断 | 逐级资源基准、低分辨率视觉起步 | 限制规模；不先假定必须换平台 |
| 云端资产或缓存依赖 | 离线不可复现 | 资产清单、授权许可、哈希与缓存 | 关键资产不可达时标BLOCKED |
| 训练／测试集泄漏 | 泛化指标虚高 | 场景与数据清单哈希、模型选择记录 | 受污染测试作废并重建保留集 |

## 4. 设计评审时应确认的选项

工作区位置与保留PX4底层已确认。本轮选择速度＋偏航率接口，首学习任务改为相对目标到达与保持；PPO、Direct工作流及独立环境方案延续。基础速度／悬停由飞控基线验证。SITL必须提前参与验证，实际硬件阶段仍另行安排。研究门限与模型参数按证据评审。

必须在M1启动前完成：模型v0所有数值、几何与来源；必须在M2长训练前完成：奖励权重、控制限值、训练预算、成功判据和固定验证集；必须在最终评估前完成：冻结checkpoint选择规则和测试manifest。这样可以先设计完整路线，同时不把未知实物信息写成事实。
